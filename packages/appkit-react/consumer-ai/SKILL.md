Read package-context.json for exact exports and peers. Install package names; import feature subpaths. Each feature guide must state its public import path. Preserve host providers and explicit CSS imports. Applications own authorization, migrations, final writes, atomic checks and durable idempotency. AI metadata consistency does not establish end-to-end coding-agent capability.

Use api-index.json for actual exported names, signatures and public import paths. Read llms.txt and the linked feature guide before choosing optional peers, host providers or CSS. Package.json appkit.agent is Appkit-specific discovery metadata, not an automatically executed agent hook. The same skill, context and catalog are present at consumer-ai/ and dist/consumer-ai/ for compatibility.

The Core package's appkit-api CLI searches locally available catalogs without running tools or contacting a provider. Check each result's package version and digest; registry 0.1.0 does not include this new CLI. Never replace a missing legacy catalog with a newer API surface. Always verify generated code with the consumer's type checker and relevant behavior tests.

AI tool calls and outputs are untrusted. Schema validity is not approval. Bind host approval to immutable arguments/targets/session/registration, enforce server permissions and durable idempotency at execution, and project minimal outputs. Adapters do not run tools or authorize writes. Read the AI guide and Core error guide; never infer permission from a tool-output event or bypass duplicate-call protection.

Drag surfaces in this candidate use native dnd-kit React. Resolve their provider
events and render refs from this installed package's API catalog; older released
guides may describe legacy contracts. Generic cancellations reach onDragEnd and
must be rejected before writes. High-level features own their native providers;
standalone registrations must share a native provider. The unreleased migration
guide is maintained in the public repository's docs/development/ directory until
a containing release can be ingested. Do not infer a published version from source.
